Nexora docs - static build (English + Arabic RTL)

Open index.html directly in a browser, or run a local server:
  python3 -m http.server 8000   then open http://localhost:8000

Pages: English in the root, Arabic in /ar.
SEO: sitemap.xml, robots.txt, llms.txt, llms-full.txt, 404.html.
