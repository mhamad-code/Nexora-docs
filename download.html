Get Started

Install Nexora on Android

Download the Nexora APK from GitHub Releases, pick the build that matches your device, and complete the first-launch setup.

Nexora is a native Android application distributed as an APK from the project's GitHub Releases page. This page walks you through downloading, installing, and completing your first launch.

System Requirements

Nexora runs on Android smartphones and tablets. There is no iOS version.

Download

Open the Releases page

Go to the Nexora Releases page in your browser.

Pick the right file

Each release contains several APK files:

File When to use it
app-arm64-v8a-release.apk Most modern phones (64-bit processor).
app-armeabi-v7a-release.apk Older phones with a 32-bit processor.
app-x86_64-release.apk Emulators and devices with an x86 chip.
app-universal-release.apk Works on all of the above, but the file is larger.

If you are not sure which one fits your device, use the universal build.

Install the APK

Open the downloaded file from your file manager. If prompted, allow Install unknown apps for your browser or file manager, then follow the on-screen prompts.

Only download Nexora from the official repository linked above. APKs from other sources may be outdated or tampered with.

To update, install a newer APK over the existing app. Releases are signed with the same key, so your data is kept.

First Launch Experience

Once Nexora is installed, open it from your home screen or app drawer. The first time you launch the app, Nexora walks you through the essential setup:

Welcome Screen

Nexora greets you with a brief welcome screen. Tap Get Started to move to the setup flow.

Add a Provider

Nexora prompts you to add at least one AI provider. Select your preferred provider — OpenAI, Google Gemini, Anthropic Claude, or a custom OpenAI-compatible endpoint — and enter your API key. You can add more providers later from Settings → Providers.

Choose a Default Model

Pick a default model for new conversations. You can always change the model on a per-conversation basis.

Start Chatting

Tap Start Chatting to open the main conversation view. Nexora is ready to use.

Import Provider Settings via QR Code

If you have already configured Nexora on another device, you can skip manual API key entry by importing your provider settings with a QR code.

How to import via QR code

On your existing device:

  1. Open Settings → Providers.
  2. Tap the Export or Share option and choose QR Code.
  3. A QR code containing your provider configuration is displayed on screen.

On your new device:

  1. Complete installation and open Nexora.
  2. On the provider setup screen, tap Import via QR Code.
  3. Point your camera at the QR code on your existing device.
  4. Nexora imports your provider settings automatically.

The QR code includes your API keys. Keep it private and do not share it publicly or screenshot it to an unsecured location.
