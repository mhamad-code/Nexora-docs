مرحبًا بك في Nexora — تطبيق دردشة بالذكاء الاصطناعي لأندرويد

Nexora تطبيق أندرويد أصلي يجمع OpenAI وGoogle Gemini وAnthropic Claude وأي مزوّد متوافق مع OpenAI في واجهة واحدة أنيقة.

يجمع Nexora كل مزوّدي الذكاء الاصطناعي الكبار في تطبيق أندرويد واحد متقن. بدل التنقل بين تطبيقات وتبويبات متصفح متعددة، تربط مفاتيح API الخاصة بك مرة واحدة وتتحدث مع OpenAI وGoogle Gemini وAnthropic Claude أو أي واجهة متوافقة مع OpenAI من الواجهة المألوفة نفسها. بُني Nexora بلغة Kotlin وJetpack Compose، فيبدو سريعًا وسلسًا ومنسجمًا تمامًا مع جهازك.
