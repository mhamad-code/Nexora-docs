البدء السريع: أرسل أول رسالة للذكاء الاصطناعي في 5 دقائق

ثبّت Nexora على أندرويد، واربط أول مزوّد ذكاء اصطناعي بمفتاح API الخاص بك، واختر نموذجًا، وأرسل أول رسالة في أقل من خمس دقائق.

يوصلك هذا الدليل من الصفر إلى أول محادثة مع الذكاء الاصطناعي بأسرع طريقة. تحتاج إلى جهاز أندرويد مثبّت عليه Nexora ومفتاح API من مزوّد واحد على الأقل. إذا لم يكن لديك مفتاح بعد، فسجّل لدى المزوّد الذي تختاره أولًا.

نزّل Nexora وثبّته

ثبّت Nexora على جهاز أندرويد من صفحة الإصدارات على GitHub.

بعد اكتمال التثبيت افتح Nexora من الشاشة الرئيسية أو قائمة التطبيقات.

افتح الإعدادات وأضف مزوّدًا

يحتاج Nexora إلى مزوّد ذكاء اصطناعي واحد على الأقل قبل أن تتمكن من الدردشة. انتقل إلى إعدادات المزوّدين الآن.

  1. اضغط أيقونة Settings (الترس) أسفل الشريط الجانبي.
  2. اختر Provider Settings من قائمة الإعدادات.
  3. كثير من المزوّدين مهيّؤون مسبقًا — إن وجدت مزوّدك فاضغط عليه وأدخل مفتاح API. وإلا فاضغط الزر في الزاوية العلوية لإنشاء مزوّد جديد.

أكثر صيغ API انتشارًا. أدخل عنوان Base URL ومفتاح API من مزوّدك لإكمال الإعداد.

لدى OpenAI إصداران من API. Chat Completions هو الافتراضي في Nexora وهو الأكثر شيوعًا وتدعمه غالبية المزوّدين. أما Responses API الأحدث فهو ما تمنحه OpenAI الأولوية الآن — فإذا كنت تستخدم واجهة OpenAI الرسمية أو وسيطًا يحاكي نماذج GPT فيُنصح بالتحويل إليه. اضغط Use Responses API لتفعيله.

صيغة API الخاصة بـ Google، وتُستخدم حصريًا مع نماذج Google Gemini.

ثاني أكثر صيغ API اعتمادًا بعد OpenAI. يستخدمها Claude وعدد من النماذج الأخرى أيضًا.

أدخل مفتاح API

الصق مفتاح API في حقل API Key للمزوّد الذي اخترته.

إذا كنت تستخدم وسيطًا غير رسمي وغير مدمج في Nexora، فستحتاج أيضًا إلى ضبط Base URL عند إنشاء المزوّد.

⚠️

تعامل مع مفتاح API كأنه كلمة مرور. لا تشاركه ولا تلصقه في تطبيقات غير موثوقة. يحفظ Nexora مفتاحك محليًا على جهازك ولا يرسله أبدًا إلى خوادم Nexora — بل يذهب مباشرة إلى المزوّد الذي اخترته.

بعد لصق المفتاح اضغط Save أو Confirm لحفظ إعدادات المزوّد.

أضف النماذج

بعد ضبط المزوّد، مرّر إلى قسم Models أسفل شاشة المزوّد واضغط عليه.

يدعم معظم المزوّدين جلب قائمة النماذج تلقائيًا — اضغط زر التوسيع لتحميل القائمة ثم اختر النماذج التي تريدها.

لحذف نموذج لم تعد بحاجة إليه، اسحبه للحذف.

ℹ️

يمكنك تغيير النموذج في أي وقت من داخل المحادثة عبر منتقي النموذج في شريط أدوات الدردشة.

اضبط النماذج الافتراضية

ارجع إلى صفحة الإعدادات واختر Default Models & Prompts لتحديد النموذج الافتراضي لكل ميزة.

إلى جانب نموذج الدردشة، يمكن لميزات أخرى (مثل توليد العناوين والتلخيص) أن تستخدم كل منها نموذجًا مختلفًا — وغالبًا ما يؤدي نموذج أسرع وأرخص عملًا جيدًا في هذه المهام.

ابدأ أول محادثة

كل شيء جاهز. ارجع إلى الشاشة الرئيسية وابدأ محادثة جديدة.

  1. اضغط زر اختيار النموذج أسفل الشاشة لاختيار النموذج الذي تريده.
  2. اكتب رسالتك الأولى في حقل النص واضغط Send.

يبثّ Nexora الرد إليك لحظة بلحظة. هذا كل شيء — أنت جاهز!

💡

جرّب بداية بسيطة مثل «اشرح لي ما الذي يمكنك مساعدتي فيه» لتتعرف على قدرات النموذج قبل الانتقال إلى مهام أكثر تحديدًا.

⚠️

تجنّب سؤال النموذج عن هويته. فالنماذج لا تملك وعيًا دقيقًا بهويتها — وهذه خاصية أساسية في طريقة عمل النماذج اللغوية الكبيرة وليست خللًا في Nexora.

تستطيع التطبيقات الرسمية الإجابة بشكل صحيح لأنها تحقن تعليمات نظام تخبر النموذج بهويته. لا يتضمن Nexora هذه التعليمات افتراضيًا، لكن يمكنك إضافتها بنفسك من إعدادات تعليمات النظام.
