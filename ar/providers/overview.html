المزوّدون

مزوّدو الذكاء الاصطناعي — اتصل بخدماتك المفضلة

تعرّف على كيفية إضافة عدة مزوّدي ذكاء اصطناعي وضبطهم والتبديل بينهم في Nexora، ومنهم OpenAI وGoogle Gemini وAnthropic Claude والواجهات المخصصة.

يتيح لك Nexora الاتصال بعدة خدمات ذكاء اصطناعي في الوقت نفسه، فتختار النموذج المناسب لكل محادثة دون مغادرة التطبيق. يُسمّى كل اتصال تضبطه مزوّدًا (provider) — ويحفظ مفتاح API وعنوان Base URL وأي خيارات إضافية لازمة للتحدث مع خدمة ذكاء اصطناعي معيّنة. يمكنك إضافة ما تشاء من المزوّدين، وتفعيل كل واحد أو تعطيله على حدة، والتبديل بين نماذجهم مباشرة من شاشة المحادثة.

أنواع المزوّدين المدعومة

يدعم Nexora أصلًا ثلاثة أنواع من المزوّدين، إضافةً إلى خيار مخصص مرن يعمل مع أي واجهة متوافقة مع OpenAI.

OpenAI

اتصل بواجهة OpenAI — بما فيها GPT-4o ونماذج الاستدلال من سلسلة o وواجهة Responses API — أو بأي خدمة تحاكي نقطة Chat Completions.
Google Gemini

استخدم نماذج Gemini مباشرة عبر Google AI API، أو استخدم Vertex AI بحساب خدمة للنشر في المؤسسات.
Anthropic Claude

تحدّث مع نماذج Claude عبر Anthropic API، مع تخزين مؤقت اختياري للأوامر (prompt caching) لتقليل زمن الاستجابة والتكلفة في المحادثات الطويلة.
مخصص / متوافق مع OpenAI

وجّه Nexora إلى OpenRouter أو نسخة Ollama محلية أو وسيط مستضاف ذاتيًا أو أي خدمة أخرى تتحدث بروتوكول OpenAI Chat Completions.

أضف أول مزوّد

افتح Settings

اضغط أيقونة Settings في شريط التنقل السفلي لفتح شاشة الإعدادات.

انتقل إلى Providers

اختر Providers من قائمة الإعدادات لعرض كل المزوّدين المضبوطين.

أضف مزوّدًا

اضغط Add Provider، واختر نوع المزوّد، واملأ مفتاح API وأي حقول مطلوبة أخرى، ثم احفظ.

أضف النماذج

داخل شاشة تفاصيل المزوّد، أضف معرّفات النماذج التي تريد استخدامها. يظهر كل نموذج في منتقي النموذج عند بدء محادثة أو التبديل بين النماذج.

إدارة عدة مزوّدين

يمكنك ضبط ما تحتاجه من المزوّدين. استخدم مفتاح التبديل في بطاقة كل مزوّد لتفعيله أو تعطيله دون حذف إعداداته. المزوّدون المعطّلون ونماذجهم تُخفى من منتقي النموذج.

إذا أردت مقارنة ردود مزوّدين مختلفين، فأضف كل واحد على حدة وبدّل النماذج بين المحادثات — دون إعادة إدخال بيانات الاعتماد.

شارك إعدادات المزوّد برموز QR

في شاشة تفاصيل كل مزوّد زر Share يحوّل إعداد المزوّد (مفتاح API وBase URL والإعدادات — دون أي نماذج مضافة) إلى رمز QR. يستطيع مستخدم Nexora آخر مسح الرمز لاستيراد الإعداد نفسه فورًا. ويمكنك أيضًا نسخ النص المشفّر وإرساله عبر أي تطبيق مراسلة.

رمز QR ونص المشاركة يحتويان مفتاح API الخاص بك. شاركهما فقط مع من تثق بهم، وألغِ المفتاح من لوحة تحكم المزوّد إذا انكشف يومًا.

التحقق من الرصيد

المزوّدون الذين يدعمون نقطة للرصيد أو الأرصدة يمكنهم عرض رصيدك المتبقي في شاشة تفاصيل المزوّد. فعّل Balance Checking في إعدادات المزوّد وحدّد مسار API ومسار الحقل في JSON الذي يحمل قيمة الرصيد. راجع صفحات المزوّدين الفردية لأمثلة خاصة بكل مزوّد.

بعض المزوّدين يحجبون الطلبات من دول أو مناطق معيّنة. إذا ظهر لك خطأ رفض وصول أو 403 فجرّب مزوّدًا آخر.
